# Alpha-GPT：Alpha-GPT: Human-AI Interactive Alpha Mining for Quantitative Investment

> - 元数据：`papers.yaml` 中 `id: alpha-gpt-2023`；路线：`llm-agent`；标签：`llm`, `human-in-the-loop`。
> - 针对问题：`P1 search-space`。
> - 来源：首轮检索整理，检索截至 2026-07-11。

* **作者单位：** 香港科技大学、IDEA Research、Columbia University、香港科技大学（广州）。

* **发表时间：** 2023.07（arXiv）。

* **论文链接：** https://arxiv.org/abs/2308.00016

* **开源项目：** 未见官方开源。

* **主要工作/创新点：** Alpha-GPT 是较早把大语言模型引入 Alpha 挖掘工作流的系统，重点不是让模型直接替代搜索算法，而是作为人类研究员自然语言想法和公式/搜索系统之间的中介。系统包含“想法生成、公式实现、结果复盘”三阶段：先把研究员的自然语言交易想法润色为结构化提示，再由量化开发代理生成初始 Alpha 公式并交给遗传规划等算法增强搜索，最后由分析代理汇总回测、IC、Sharpe 等指标，并用自然语言反馈给人类。系统还设计交互模式和自主模式；后者用层次化检索增强生成（RAG）在大规模数据字段库中逐层检索，从高层类别缩小到具体字段，缓解上下文窗口不足。

* **可参考点：** 1）把 LLM 定位为“想法到公式”的编译/反编译器；2）用 LLM 总结搜索结果并指导下一轮人工或自动搜索；3）层次化 RAG 适合处理字段很多的另类数据或高频特征库；4）可与本地 GP/RL 搜索器组合，而不是让 LLM 独立完成全部挖掘。
