# Alpha2：Alpha2: Discovering Logical Formulaic Alphas using Deep Reinforcement Learning

> - 元数据：`papers.yaml` 中 `id: alpha2-2024`；路线：`formulaic`；标签：`rl`, `mcts`, `program-search`。
> - 针对问题：`P1 search-space`。
> - 来源：首轮检索整理，检索截至 2026-07-11。

* **作者单位：** 南京大学新型软件技术全国重点实验室、南京大学人工智能学院、香港大学。

* **发表时间：** 2024.06。

* **论文链接：** https://arxiv.org/abs/2406.16505

* **开源项目：** https://github.com/x35f/alpha2（仓库说明为伪代码和算法结构，不是完整可运行复现）。

* **主要工作/创新点：** Alpha2 将公式化 Alpha 生成重新表述为程序构造，而不是线性 RPN 符号拼接。每条指令包含算子、操作数和寄存器，程序可转化为表达式树；寄存器保存中间结果，使系统可以在搜索阶段维护维度信息，提前剪枝不符合金融逻辑的动作，例如禁止价格与成交量直接相加。搜索算法结合强化学习引导的 MCTS，用策略网络给出动作先验概率，用价值网络估计当前程序继续扩展后的潜力；价值备份不只使用均值，也混合最大值和排名前 k 的高分结果，以缓解稀疏高价值空间中的低估，同时避免纯最大值备份带来的过拟合。评价函数还加入与已挖因子的相关性折扣，鼓励持续发现多样因子。

* **可参考点：** 1）用 program/register 表示提升约束可控性；2）维度一致性检查可以显著减少无意义表达式；3）mean/max 混合 value backup 可用于稀疏高价值搜索；4）逻辑合法性应在生成阶段前置，而不是生成后过滤。
