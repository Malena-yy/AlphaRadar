# 论文笔记规范

适用于 `notes/` 下的速读卡、精读和模板，是 [仓库协作规范](../AGENTS.md) 的补充。

## 文献与证据

- 笔记依据论文正文及附录，注明文献版本。代码发布状态与链接保留在元数据中，源码分析、复现和独立实验不属于论文笔记的证据范围。
- 可以解释论文中的伪代码、算法、公式与实验设计；机制、参数和设置须有原文依据。
- 区分作者主张、论文证据、公式推导与分析者推断。材料未纳入分析与论文未披露分别说明；关键结论就近注明章节、公式、算法或表格。
- 结果保留影响判断的市场、切分、评价单位、指标、预算和成本。跨论文比较说明口径差异，组件归因结合对照设计，相关性观察按其证据范围表述。

## 论证结构

按“已有困难 → 关键观察 → 方法设计 → 实验证据 → 研究结论”建立论证，章节名称与数量按论文类型调整。

1. **已有困难**：任务目标、必要输入输出、相关方法及其局限。
2. **关键观察**：作者的观察、核心假设或设计依据；依据原文归纳时说明其性质。
3. **方法设计**：先说明整体框架，再解释关键机制及其与困难的关系。多阶段方法明确模块分工、执行顺序、反馈信息和参数更新。
4. **实验证据**：说明验证目的、设置与对照、结果和支持范围，区分整体效果、组件贡献与相关性观察。
5. **研究结论**：概括证据支持的贡献、适用条件和局限；披露缺口聚焦影响核心结论的内容。

## 速读与精读

- **速读卡**使用 [卡片模板](_template_card.md)，压缩呈现关键机制与证据，保留“主要工作/创新点、针对问题与证据、局限”三个字段。
- **精读**使用 [精读模板](_template_deep.md)，展开论证、必要公式和案例。章节标题须包含“核心结论、针对的问题、实验、未披露”，正文组织按论文实际内容确定。
- P1–P10 作为辅助索引，映射保持简短。卡片问题行使用 `P<k> <问题名>（主要|涉及）：<机制>`，先主要后涉及，与登记一致；基线或背景工作写“无（作为基线或背景工作收录）。”。
- 相邻方法说明原任务到因子挖掘的迁移关系与条件，区分直接借用、机制相似与迁移设想。
- 速读卡不设“可参考点”。精读在有明确迁移启示时讨论方法思想及适用条件，否则省略。

## 行文与格式

- 使用客观、准确的书面技术语言，标题概括研究对象、机制或实验目的。术语首次出现时解释；公式采用纯文本，保留必要符号定义及原文编号。
- 内容通过定义、机制关系和必要示例展开，避免对话措辞、口语类比、拟人化与宣传性判断。
- 案例就近解释对应机制，自构示例明确标为示意。关键条件就近交代，其他局限集中说明，重复内容通过引用衔接。
- 笔记正文只呈现研究分析、文献来源及证据边界。元数据由脚本生成，修改范围以所涉及的论文和事实为准。
