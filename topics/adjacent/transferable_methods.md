# 可迁移到因子挖掘的相邻方法

> 本文选取 `adjacent` 路线中的生成、信用分配与统计推断方法，比较它们在原领域的作用及迁移条件。直接采用、机制相似与迁移设想分别说明；下文迁移分析不是原论文对因子挖掘的实验证据。其他相邻工作见[论文索引](../../INDEX.md#by-route)。

## 2. 迁移点

### 2.1 高分位策略更新：DSR

DSR 将符号回归表达式自回归生成，用批内奖励分位数作基线，只用高分尾部更新。它针对最终寻找少数高分表达式的目标，区别于标准策略梯度的期望回报目标。RiskMiner 采用相同的风险寻求思路，但仅凭这一关联不能证明实现直接继承。

迁移时要注意：在低信噪比的 IC 上，只追高分尾部更容易选中偶然的高分，需要配合独立的样本外检验（对应 P5）。

### 2.2 奖励比例采样：GFlowNet 与 Trajectory Balance

GFlowNet 以奖励比例分布为采样目标，在奖励与训练条件满足时可保留多个高奖励模式。它支持离策略训练，原方法将代理奖励与少量真实评价结合；迁移时仍须评价代理误差。Trajectory Balance 用整条轨迹残差训练前后向概率与总流量。若完整 token 前缀状态只有唯一前驱，P_B=1，损失简化为 `L_TB = (log Z + sum_t log P_F - log R)^2`。这不能直接视为 AlphaSAGE 的后向策略实现；其公式与边界见[训练机制对照](../generator_training_with_ic.md)。

迁移时要注意：

- 合成奖励须严格为正，且取绝对值、平移或指数变换会改变目标分布，不能作为无关实现细节处理。
- 对树状构造图，TB 论文讨论了 GFlowNet 与适当熵正则 RL / soft Q-learning 的关系；需要对应终端 log 奖励等条件，不能由“都加熵”推出普通 IC-PPO 与 GFlowNet 等价。
- 若因子池影响奖励，目标分布及 log Z 会随池变化；有限优化是否能追踪该目标需检验。

### 2.3 LLM 代码演化的工程接口：DeepMind AlphaEvolve

初始程序、可演化代码块、返回指标字典的评价函数与分级评价，为代码因子搜索提供接口参考。FactorEngine 与 CogAlpha 使用同类 LLM 代码演化；迁移仍需加入行情数据契约、沙箱与时间可用性约束。

迁移时要注意：固定数据上的 IC 可确定计算，但它对未来预测能力的估计仍有噪声。反复评价与择优会引入选择偏差，需要独立评价与搜索过程诊断；级联初筛还可能误删有效候选（对应 P3、P5、P6）。

### 2.4 多轮智能体的步骤级信用：GiGPO 与 Tree-GRPO

两者都不训练 critic，但采样方式不同：GiGPO 对已有轨迹中的重复状态分组，不增加 rollout；Tree-GRPO 从中间步骤续写分支，复用前缀并比较兄弟子树。向 AlphaPilot、AlphaDiverse 等多轮因子智能体迁移时，可以研究状态组或分叉点的相对信用，但尚不能据此声称已在这些系统中验证。

迁移时要注意：

- 公式相同不保证智能体状态相同：池、历史反馈、预算与可用工具也影响后续决策。仅按 AST 归组可能混合不同决策条件。
- 前缀共享主要节省已完成的生成与中间工具调用，新增叶节点仍需独立评价；节省比例取决于各环节成本。
- IC 差异的噪声与小组规模影响优势估计。树间基线可以稳定相对信号，但不能代替统计校准或独立评价。

### 2.5 选择模型与候选族推断：Publication Bias 与 Sequential Cauchy

这两篇不是因子挖掘方法，但提供了分析选择偏差的工具。Publication Bias 在显式的发表选择模型下，由 t 值分布估计经验贝叶斯收缩与方向错误风险，并区分选择偏差与真实收益变化对样本外衰减的影响；Sequential Cauchy 从一族有效 p 值指认具体拒绝项，无需估计相关矩阵，但强 FWER 控制依赖分布假设与渐近条件。

迁移时要注意：

- Sequential Cauchy 需要明确检验族与有效 p 值；Publication Bias 可以在选择模型与识别假设下估计偏差，不必预先知道所有未发表试验数。QBX 的试验计数改善可追溯性，但不能替代这些推断前提。
- EvoQuantLab 的等预算区块置换检验的是搜索赢家，不是逐个候选；重采样仍依赖零假设构造与搜索重放的范围，不能将其 p 值直接当作 Sequential Cauchy 所需的候选族输入。详见[搜索规模与过拟合校正](../search_multiplicity.md)。
- “提高因子入选门槛”不等于做了多重检验校正，“去掉流动性等风格暴露”也不等于消掉了数据窥探——Publication Bias 原文专门澄清了这两点。

## 3. 迁移分析的适用范围

相邻领域的成功结果不构成因子挖掘的性能证据。迁移比较需明确目标是否从确定性恢复变成带噪预测、状态是否包含因子池与反馈，以及验证数据是否独立。公式可读与低相关也不能单独证明经济解释或组合增量。

符号回归的连续常数拟合可参考 DSR 的内循环，但整数窗口、时序依赖与截面 IC 目标不同于独立数据行上的最小二乘。此类优化不能未经对照就替代因子评价。
