# AlphaRadar

![AlphaRadar 因子挖掘研究地图：遗传规划、神经网络、强化学习与大语言模型](assets/readme-cover.png)

AlphaRadar 面向因子挖掘研究者，收录和分析公开论文，比较各工作针对的问题、采用的机制、实验证据与适用边界。范围包括公式 / 符号 / 代码因子、大语言模型（LLM）因子生成与研究流程、神经因子、因子池与组合、评估与审计，以及可迁移的相邻方法。

内容包括论文登记、简读卡、精读、横向专题与跟踪简报。简读卡概括贡献与证据，精读展开论文论证，专题比较不同工作。笔记注明所据版本与证据范围；论文结果以原文为准，跨论文比较保留市场、切分、标签与成本的差异。文中 IC（Information Coefficient）指因子值与目标收益的相关性，RankIC 指相应的秩相关；具体定义与标签期限按论文区分。

本仓库提供文献分析，所述实验证据来自引用的公开材料；不提供策略实现或独立回测验证。

## 因子挖掘面临的问题

因子挖掘关注如何在有限预算下寻找具有预测能力的信号，并检验其样本外有效性、互补性与组合价值。本仓库用 P1–P10 组织相关困难，作为阅读和比较工作的分析框架；这些问题可以相互关联，也可以在同一方法中同时出现。

问题大体沿表达、搜索、评价、训练与使用等环节组织。标注分为“主要针对”（论文动机及主要贡献，至多 3 个）与“顺带涉及”（有对应机制，但不是主要贡献）。表中数字是已收录工作的篇数，一篇可标注多个问题；计数表示文献覆盖，不代表机制已验证有效或问题已解决。

几处容易混淆的边界：

- **P3 与 P4**：P3 关注搜索与评价成本，P4 关注反馈如何用于学习生成策略。同一机制可以同时针对两者，例如 [AlphaForge](notes/deep/2024_AlphaForge.md) 的预测器既辅助候选评价，也为生成器提供可微信号。
- **P5、P6、P9**：三者都可能导致样本外表现下降。P5 关注拟合与选择偏差，P6 关注未来信息进入研究或评价，P9 关注市场分布、有效关系与拥挤程度的变化。
- **先验知识**（研究员想法、研报、专家因子）不单列为问题，它是应对 P1 的一类手段。
- **代码生成中的问题**：不可执行属于候选无效（P1），声称的逻辑与实现不一致涉及可解释性（P2）；这些边界适用于各种代码生成方法。

以下逐条说明问题。“跟踪关注点”列出比较方法时需要考察的证据与条件。

### P1 表达空间巨大，有效因子稀少

算子、字段、窗口和常数形成庞大的组合空间，其规模随允许的表达式长度迅速增长。候选可能违反语法或类型约束、无法执行、缺少有效预测信息，或与已有表达式语义等价。若生成过程不能提前识别这些情况，评价预算就会用于大量无效或重复候选。

跟踪关注点：约束前置能节省多少评价预算？约束和先验会不会把有效区域也排除掉？

### P2 表达能力与可解释性的权衡

公式便于检查计算过程，但表达能力受算子集与数据类型限制，可读的公式也不自动具有经济解释。神经表示和通用代码可以扩展表达能力，同时增加结构解释与执行审计的难度。引入外部信息还需要明确其可用时间与来源。因子声称的经济逻辑应与实际计算一致。

跟踪关注点：表达能力提升带来的增益，在样本外能保留多少？神经因子和代码因子如何审计？

### P3 评价成本高

完整评价通常需要在行情面板上计算因子值、预测能力与因子间相关性；市场范围、样本长度和池规模都会影响成本。LLM 方法还承担推理成本，代理评价、缓存与分级筛选则可能减少真实求值次数。比较搜索效率需要同时明确预算单位与评价范围。

跟踪关注点：各方法是否在相同评价预算下比较？代理模型的误差在哪里会误导搜索？

### P4 学习信号稀疏、延迟且不可微

对离散公式生成，完整候选评价常提供终端反馈，难以直接区分各步动作的贡献；真实 IC 无法经离散 token 选择直接反向传播。若奖励依赖当前因子池，池更新还会改变同一候选的评价。中间奖励、代理模型、偏好学习与轨迹目标分别尝试改善这些学习信号，其适用条件需要区分。

跟踪关注点：中间反馈或代理目标是否与终端评价一致？奖励塑形是否引入偏差？池依赖的非平稳奖励下，不同训练目标的稳定性如何？

### P5 低信噪比下的过拟合

股票收益的信噪比通常较低。反复评价并择优会引入选择偏差，训练期的高分可能包含偶然拟合；候选与协议根据既有结果调整，还会增加自适应选择的复杂性。搜索并不一定执行了显式假设检验，但显著性判断需要考虑多重比较，不能将最佳候选的分数当作未经选择的证据。

跟踪关注点：是否记录完整候选、协议选择与停止规则？搜索诊断是否重放自适应选择？候选冻结后的评价是否独立？计数、搜索过程检验与候选族校正的区别见[搜索规模与过拟合校正](topics/search_multiplicity.md)。

### P6 前视偏差与信息泄漏

标签窗口、字段发布时间、复权、停牌与股票池成分处理若使用了决策时不可获得的信息，就可能制造虚假的预测能力。测试期参与选因子或选协议也会破坏评价独立性。LLM 方法另需考虑预训练知识与评估区间的重叠；仅凭最终表现无法判断这些边界是否得到遵守。

跟踪关注点：是否说明数据在决策时的可用性、训练与评价的信息隔离，以及 LLM 知识截止与测试区间的关系？编译期检查、协议审计与知识截止基准各自覆盖哪些风险？

### P7 因子同质化与冗余

单一高分目标可能使搜索集中到少数模板，生成器也可能出现模式坍缩。公式结构不同并不保证信号互补；因子高度相关可能限制新增信息并集中组合暴露，但相关性本身不足以判断边际价值。多样性需要在结构、历史行为与下游组合等层次分别评价。

跟踪关注点：如何识别结构不同但行为相似的因子？多样性约束是否改善信号互补性，其与单因子质量的取舍如何？

### P8 挖掘目标与实际使用脱节

因子用于下游预测或组合配置时，单因子 IC 未必代表新增价值。组合方式、权重变化与已有信号都会影响边际贡献；用于交易时，还需考虑换手、容量和成本。挖掘目标与使用目标之间的差异，需要通过共同组合器或其他受控对照评价。

跟踪关注点：是否报告组合换手并在收益中计入交易成本？动态组合的增益来自因子本身，还是来自组合器？

### P9 非平稳与因子衰减

市场分布与经济关系可能随时间变化，交易拥挤也可能削弱既有信号。因子表现下降可能来自非平稳，也可能来自过拟合或评价误差，需要区分成因。滚动重训、动态筛选与在线更新提供适应机制，其效果与成本仍需评价。

跟踪关注点：是否直接度量信号衰减并区分成因？在线更新或滚动重训的效果与成本如何？

### P10 评估口径不统一、难以复现

各工作使用不同的市场、股票池、时间切分、标签、IC 或 RankIC 口径、组合方式和成本假设，报告的数字通常不能直接横向比较。论文、公开代码、数据处理与实验配置是否对应，也会影响结果的可复核性；提供代码链接本身不足以保证复现。

跟踪关注点：共同基准统一了哪些条件，又保留了哪些方法差异？同一方法在不同论文中作为基线时，设置是否一致？所报结果能否对应到公开版本、配置与数据口径？具体差异见[评估口径对照](topics/evaluation_protocol.md)。
